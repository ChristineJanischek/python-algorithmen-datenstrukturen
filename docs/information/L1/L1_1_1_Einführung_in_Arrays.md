## 🎯 Einführung

Arrays sind eine fundamentale Datenstruktur in der Programmierung.

## 📖 Inhalt

Ein Array ist eine geordnete Sammlung von Elementen des gleichen Datentyps.

**Eigenschaften:**
- Feste oder dynamische Größe
- Zugriff über Index (beginnt bei 0)
- Effizient für sequentiellen Zugriff

**Beispiel in Python:**
```python
zahlen = [1, 2, 3, 4, 5]
print(zahlen[0])  # Ausgabe: 1
```
