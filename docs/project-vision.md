# Projektvision: Didaktischer Lernagent

## Kurzform

Ein adaptiver KI-gestützter Lernassistent für Informatik im Berufskolleg und Beruflichen Gymnasium Baden-Württemberg.

## Langfristige Vision

Der Lernagent wird Bestandteil eines intelligenten, webbasierten E-Learning-Systems für Informatik.
Das System soll kein klassisches LMS (wie Moodle) nachbilden,
sondern **Lernen, kreatives Problemlösen und Softwareentwicklung** unterstützen.

Perspektivisch geplante Bereiche:

- adaptive Lernpfade
- gestufte Hilfestellungen
- formative Rückmeldungen
- Lernstandsanalysen
- Aufgabengenerierung und -varianten
- Erkennung häufiger Fehler und Fehlvorstellungen
- Programmieraufgaben und Codeboxen (Python, Java, PHP, HTML/CSS/JavaScript)
- Datenbanken, SQL und Normalisierung
- Softwareentwicklung, UML, BPMN und Modellierung
- KI und Machine Learning als Lerninhalt
- wiederverwendbare Lernmodule (Markdown + JSON)
- kollaborative Entwicklung über GitHub
- spätere Integration in MindLink
- Lerncoach-Avatare

## Aktueller Stand (MVP)

Das MVP ist eine **Konsolenanwendung**, die:
- Lerngebiet, Thema, Niveau und Lernziel abfragt
- eine Frage oder einen Lösungsversuch entgegennimmt
- gestufte didaktische Rückmeldungen gibt
- vollständig ohne API-Schlüssel mit MockProvider funktioniert

## Entwicklungsprinzipien

- Schüler sollen die fachlich interessanten Teile selbst implementieren
- Klare Schnittstellen erlauben parallele Entwicklung
- Einfacher, verständlicher Code vor eleganter Abstraktion
- Datenschutz und Transparenz von Anfang an
