# Aufgabe: Array-Summe berechnen

## 📋 Übersicht

- **Level:** L1
- **Kategorie:** 3
- **Zeitaufwand:** 15 Minuten

**Themen:**
- Arrays
- Schleifen
- Summierung

**Lernziele:**
- Array durchlaufen können
- Summe akkumulieren können

## 📝 Problemstellung

Schreibe ein Programm, das die Summe aller Elemente eines Arrays berechnet.

## 📊 Struktogramm

```
Deklaration und Initialisierung: zahlen = [5, 10, 15, 20]
Deklaration und Initialisierung: summe = 0
Deklaration und Initialisierung: n = Anzahl der Elemente des Arrays zahlen
Zähle i von 0 bis n - 1, Schrittweite 1
    Zuweisung: summe = summe + zahlen[i]
Ausgabe: "Summe: " + summe
```

## 🧪 Beispiel

**Eingabe:**
```
[5, 10, 15, 20]
```

**Erwartete Ausgabe:**
```
Summe: 50
```
