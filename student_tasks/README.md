# Schüleraufgaben: Didaktischer Lernagent

Willkommen im Projekt **Lernagent**!

Hier findest du alle Arbeitsaufträge für die Entwicklung des Lernagenten.
Die Aufgaben bauen aufeinander auf, können aber teilweise parallel von verschiedenen Teams bearbeitet werden.

## Übersicht

| Nr. | Aufgabe | Schwierigkeit | Dateien |
|-----|---------|--------------|---------|
| [01](01-hint-levels.md) | Intelligente Hilfestufen-Auswahl | ⭐⭐ | `hint_levels.py` |
| [02](02-prompt-strategies.md) | Verbesserte Prompt-Strategien | ⭐⭐ | `system_prompt.py` |
| [03](03-error-analysis.md) | Fehlerklassifikation | ⭐⭐⭐ | `input_check.py`, neue Datei |
| [04](04-learning-content.md) | Lernmodul-Validierung | ⭐⭐ | `loader.py`, `schemas/` |
| [05](05-testing.md) | Testabdeckung erweitern | ⭐ | `tests/` |
| [06](06-reflection-and-transfer.md) | Reflexions- und Transferfragen | ⭐⭐ | `feedback.py`, `hint_levels.py` |

## Arbeitsablauf

1. Issue im Repository übernehmen.
2. Branch erstellen: `feature/aufgabe-01-dein-name`.
3. Aufgabe umsetzen und testen.
4. Pull Request erstellen (verknüpft mit `Closes #Issue`).
5. Code Review durch eine andere Gruppe.

Lies zuerst `docs/git-workflow.md` und `docs/student-setup.md`.

## Hinweis

Erstelle **keine vollständigen Musterlösungen** in öffentlichen Dateien.
Der Lernprozess liegt im Entwickeln – nicht nur im Lauffähigmachen.
